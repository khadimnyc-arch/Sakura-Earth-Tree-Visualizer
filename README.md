# Sakura Earth Tree Visualizer

An object-oriented Processing application written in Java that programmatically renders a blossoming pink sakura (cherry blossom) tree with interactive petal physics.

## Features

* **Procedural Tree Generation:** Draws a detailed sakura tree trunk and branch structure using geometric transformations.
* **Object-Oriented Petals (`Petal.java`):** Manages individual cherry blossom petals as discrete objects, giving them randomized drift and falling animations across the canvas.

## How to Run

1. Clone or download this repository.
2. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
4. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
